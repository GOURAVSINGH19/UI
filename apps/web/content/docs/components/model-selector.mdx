## Usage

The menu scales out of the trigger with a soft blur, a highlight slides between rows as
you hover or arrow through them, and the trigger's label blurs over to the new model when
you pick one.

```tsx
import { ModelSelector } from "@/components/ui/model-selector"

const models = [
  { id: "kinetik-2", name: "Kinetik 2", description: "Smartest for everyday work", badge: "New", color: "#7c5cff" },
  { id: "kinetik-fast", name: "Kinetik Fast", description: "Quick answers", color: "#06b6d4" },
]

export function Picker() {
  const [model, setModel] = useState("kinetik-2")
  const [thinking, setThinking] = useState(false)
  return (
    <ModelSelector
      models={models}
      value={model}
      onValueChange={setModel}
      thinking={thinking}
      onThinkingChange={setThinking}
    />
  )
}
```

Use `side="top"` when it sits inside a prompt box at the bottom of the screen.

## Accessibility

- The trigger opens a `listbox`; the highlighted row is exposed with `aria-activedescendant`
- Arrow keys, Home and End move the highlight, skipping disabled models; Enter or Space picks
- Escape closes and returns focus to the trigger; the thinking switch is a real `switch`
