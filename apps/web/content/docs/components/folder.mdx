## Usage

Hover or click to open. Each paper springs out with a small delay after the one
before it, so they fan out instead of moving as a block.

```tsx
import { Folder } from "@workspace/ui/components/ui/folder"

export function Files() {
  return <Folder color="#e0a030" flap={["#f3c25e", "#eab14a"]} />
}
```

Control it yourself with `open` and `onOpenChange`, for example to open the
folder while something is being dragged over it.

```tsx
const [open, setOpen] = useState(false)

<Folder open={open} onOpenChange={setOpen} />
```

## Accessibility

- The folder is a real `button` with `aria-expanded` and a label that switches
  between “Open folder” and “Close folder”
- Keyboard users toggle it with Enter or Space
