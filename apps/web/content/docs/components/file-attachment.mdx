## Usage

Images show as thumbnails that sharpen as they upload. Other files show as a chip with a
coloured extension tile and a live “1.2 MB of 3.4 MB” line. When an upload finishes the
ring pops into a check; when it fails the tile turns red with a retry button.

```tsx
import { AttachmentList, type Attachment } from "@/components/ui/file-attachment"

const files: Attachment[] = [
  { id: "1", name: "photo.png", size: 2_400_000, type: "image/png", url: previewUrl, progress: 0.4, status: "uploading" },
  { id: "2", name: "report.pdf", size: 1_200_000, progress: 1, status: "done" },
]

<AttachmentList
  items={files}
  onCancel={(id) => abortUpload(id)}
  onRetry={(id) => startUpload(id)}
  onRemove={(id) => removeFile(id)}
/>
```

You drive `progress` and `status` from your upload code. Leave `progress` undefined for a
spinning ring when the size is unknown. `ProgressRing` and `AttachmentPreview` are exported
on their own too.

## Accessibility

- Cancel, retry and remove are labelled buttons that name the file
- A polite status line announces how many files are still uploading
- Respects `prefers-reduced-motion`
