## Usage

This is the same search as the one in this site's navbar. Press <kbd>⌘K</kbd> / <kbd>Ctrl K</kbd> to try it on real pages.

Pass it a flat list of items. Each item belongs to a `group`, which is used for the
result headings and the filter menu. While the field is empty, the placeholder cycles
through your item titles.

```tsx
import { useRouter } from "next/navigation"
import { SimpleSearch, type SimpleSearchItem } from "@/components/ui/simple-search"

const items: SimpleSearchItem[] = [
  { title: "Home", href: "/", group: "Pages" },
  { title: "Button", href: "/docs/button", group: "Components", badge: "New" },
  { title: "Theming", href: "/docs/theming", group: "Guides", description: "Colours and dark mode" },
]

export function Search() {
  const router = useRouter()
  return <SimpleSearch items={items} onSelect={(item) => item.href && router.push(item.href)} />
}
```

To open it from your own button, control it with `open` and `onOpenChange` and set
`showTrigger={false}`.

## Accessibility

- The input is a `combobox` that controls a `listbox`; the highlighted result is
  exposed with `aria-activedescendant`
- ↑ ↓ move through results across groups, Enter opens, Escape closes and returns
  focus to the trigger
- The filter menu is its own `listbox` with arrow keys; Escape closes just the menu
- Animations are skipped when the visitor prefers reduced motion
