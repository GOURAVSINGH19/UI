No packages to install: it is one file with its own styles, plain React and the Web Audio API.

## Usage

Give it a list of tapes. A `cover` can be the built-in `TapeCover`, an `<img>`, or any JSX.
Without a `src`, each tape plays a small generated beat at its `bpm`.

```tsx
import { TapeDeck, TapeCover, type TapeItem } from "@/components/ui/tape-deck"

const tapes: TapeItem[] = [
  {
    id: "imgnest",
    title: "ImgNest",
    artist: "Next.js · PostgreSQL",
    cover: <TapeCover background="#2fc0c9" color="#0b2e33" text={"IMG\nNEST"} side="A" />,
  },
  {
    id: "craftui",
    title: "CraftUI",
    artist: "React component library",
    cover: <img src="/covers/craftui.png" alt="" />,
    src: "/audio/craftui.mp3",
  },
]

export function Shelf() {
  return <TapeDeck tapes={tapes} className="h-[600px]" />
}
```

To restyle it, override `--fg`, `--muted`, `--line` and `--bg` on the deck. To keep music playing after a
tape closes, create a player with `useTapePlayer` outside and pass it as `player`.

## Accessibility

- Every tape is a focusable button; Enter or Space opens it
- ← → move along the shelf, or between tapes once one is open; Space plays or pauses; Escape closes
- Vertical page scroll is left alone: only horizontal scroll or drag moves the shelf
- With reduced motion on, tapes jump into place and the reels stop spinning
