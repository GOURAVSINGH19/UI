No dependencies: it is plain React, Canvas and the Web Animations API.

## Usage

Attach `ref` to the element and call `dissolve()`. The element is copied into pixels, each
pixel becomes a particle in its own colour, and the dust sweeps away on the wind. The promise
resolves once the dust is gone, which is when you remove the item from your data.

```tsx
import { useDissolve } from "@/components/ui/particle-dissolve"

function Message({ message, onDelete }) {
  const { ref, dissolve } = useDissolve<HTMLDivElement>({ from: "left" })

  return (
    <div ref={ref}>
      <p>{message.text}</p>
      <button
        onClick={async () => {
          await dissolve()
          onDelete(message.id)
        }}
      >
        Delete
      </button>
    </div>
  )
}
```

Outside React, call `dissolve(element, options)` directly. `restore(element)` brings a dissolved
element back, for an undo.

Space between items should come from margins, not a flex `gap`, so the fold animates smoothly.
Add `data-dissolve-ignore` to anything you don't want in the dust, such as the delete button.

### How it stays fast

- One canvas for the whole page, and its loop only runs while dust is moving
- Particles live in typed arrays, not one object each, and finished ones are swapped out in place
- Large elements are sampled more coarsely so they never pass `maxParticles`
- Colours are grouped so the canvas rarely has to change paint

## Accessibility

- The dust canvas is decorative and hidden from screen readers
- The element is made `inert` while it dissolves, so it can't be focused or clicked twice
- With `prefers-reduced-motion`, the element simply fades out and folds
- Announce the change yourself (for example a "Message deleted" toast), since the effect is visual only
