## Usage

The input and the results panel are drawn as two blobs behind an SVG goo filter.
As the panel grows, the gap between them springs open so the results look like
they pull away from the input.

```tsx
import { GooSearch } from "@/components/ui/goo-search"

const items = [
  { title: "Button", href: "/docs/components/button", category: "Components" },
  { title: "Theming", href: "/docs/theming", category: "Guides" },
]

export function Search() {
  return (
    <GooSearch
      items={items}
      onOpen={(item) => console.log(item.href)}
      placeholder="Search components…"
    />
  )
}
```

To render results as real links, set `linkResults` and pass your router's link
component, e.g. `linkAs={Link}` from `next/link`.

## Accessibility

- The input is a `combobox` that controls a `listbox`; the highlighted result is
  exposed with `aria-activedescendant`
- Arrow keys move through results across groups, Enter opens the active one
- Every keyboard hint is also a button, so the component works without a keyboard
