## Usage

Wrap any area. Every click inside it sends sparks out from the cursor.

```tsx
import { ClickSpark } from "@/components/ui/click-spark"

export function Page() {
  return (
    <ClickSpark sparkCount={10} sparkRadius={24}>
      <main>…</main>
    </ClickSpark>
  )
}
```

The sparks use the wrapper's text colour by default, so they follow light and dark mode.
Pass `sparkColor` to pin a colour.

### Bursts and triggers

Pick a shape with `burst`: straight `lines`, swirling `curves`, `dots`, a single expanding
`ring`, or spinning `stars`. Set `trigger="dblclick"` to fire only on a double click, so normal
clicks stay quiet.

```tsx
<ClickSpark burst="curves">…</ClickSpark>

<ClickSpark burst="stars" trigger="dblclick">…</ClickSpark>
```

### Sound

Set `sound` to play a soft synthesised tick on every click, or pass a URL to use your own file.
Files are fetched once and decoded, so quick clicks overlap without lag.

```tsx
<ClickSpark sound volume={0.3}>…</ClickSpark>

<ClickSpark sound="/sounds/pop.mp3">…</ClickSpark>
```

## Accessibility

- The canvas is decorative, hidden from screen readers and ignores pointer events
- Clicks pass through to the children as normal
- Sound is off by default, since unexpected audio can be disruptive
