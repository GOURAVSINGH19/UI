## Usage

Hover the card or focus a field and the plant grows; leave and it retracts.
Pass `active` to keep it grown, for example after a form is sent.

```tsx
import OrganicGrowth from "@/components/ui/organic-growth"

export function Card() {
  return (
    <OrganicGrowth padding={70}>
      <div className="rounded-2xl border p-6">Hover me</div>
    </OrganicGrowth>
  )
}
```

Each vine is described by a `Sprout`: which edge it grows from, where along that
edge, which way it bends, how long it is, and how it ends.

```tsx
const sprouts: Sprout[] = [
  { edge: "top", t: 0.2, side: -1, length: 60, end: "curl" },
  { edge: "right", t: 0.5, side: 1, length: 80, end: "bloom", blooms: [0.5] },
]
```

The plant is built from a seeded random generator, so the same `seed` always
gives the same arrangement. Colours read `--og-*` CSS variables, or pass a
`palette` to override them.

## Accessibility

- The plant is a decorative `aria-hidden` SVG behind your content, which stays
  fully interactive
- With `prefers-reduced-motion`, vines fade in instead of growing
- On touch screens, tapping the element grows it and tapping elsewhere retracts it
