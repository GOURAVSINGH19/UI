## Usage

At rest the input is a small pill. Focusing it springs it open to full width and the
toolbar blurs in: an attach menu, a model picker, the mic and the run button. It folds
back once focus leaves and nothing is typed or attached.

The **+** button opens a menu like ChatGPT's: add photos and files or take a photo, then pick a
tool (Create image, Deep research, Web search, Think longer). A picked tool shows as a blue chip
beside **+**, changes the placeholder, and arrives in `onSubmit` as `tool`; click the chip to turn
it off. Pass your own list with `tools`. The model picker is the [Model Selector](/docs/components/model-selector) component, so it keeps
the same badges, colours, sliding highlight and keyboard support. Copy its
`components/ui/model-selector/` folder too; both folders are in the Code tab.

The glow around the box is [Beam](https://libraries.dev/beam) (`border-beam` on npm) by
[Libraries.dev](https://github.com/Jakubantalik/Libraries.dev). It switches on when the box opens and
speeds up while a prompt is running. Install it with `npm install border-beam`, and see its docs to
tune the glow.

```tsx
import { PromptInput } from "@/components/ui/prompt-input"

export function Chat() {
  return (
    <PromptInput
      onSubmit={async (value, { attachments, model, tool, signal }) => {
        await fetch("/api/chat", {
          method: "POST",
          body: JSON.stringify({ value, model, tool }),
          signal,
        })
      }}
    />
  )
}
```

Return a promise from `onSubmit` and the run button turns into a stop button until it
settles. Pressing stop aborts `signal` and calls `onStop`.

Images can be added from the menu, dropped onto the input, or pasted into the text.

## Accessibility

- Enter runs, Shift + Enter adds a new line, Escape leaves the input
- Menus open on Enter or Space, move with the arrow keys and close on Escape, returning focus to their button
- Run, stop, mic and remove buttons all have labels; running and listening are announced
- Respects `prefers-reduced-motion`: the beam stays off and springs become instant
