## LinkedIn

Every AI product needs a model picker, and most of them feel like a plain dropdown.

So I built one for Kinetik, my open source component library, that's a bit nicer to use:

• The menu scales out of the trigger with a soft blur, so it feels like it grows from the button
• A highlight slides between rows as you hover or arrow through them
• Picking a model blurs the label over to the new name instead of just swapping it
• An optional "Extended thinking" switch sits right in the menu
• Badges like New and Pro, plus disabled "coming soon" models
• It works fully from the keyboard: arrows, Home/End, Enter, Escape, with proper listbox semantics for screen readers

Built with React, Tailwind CSS and Motion. Copy it into your project and make it yours.

Code: https://github.com/GOURAVSINGH19/UI
